La fonction cube

Découvrez f(x) = x³ et ses propriétés

Définition

La fonction cube

La fonction cube est la fonction f définie sur ℝ par :

f(x) = x³

Elle associe à chaque nombre réel x son cube x³. Par exemple :

x−2−10123
x³−8−101827
Graphique interactif

Courbe de y = x³

Passez la souris sur la courbe pour lire les valeurs !

→ Survolez la courbe
3 propriétés à retenir
1

Symétrie par rapport à l'origine O

Si le repère est orthogonal, la courbe admet O comme centre de symétrie. Cela signifie que f(−x) = −f(x).

2

Fonction impaire

Pour tout réel x : f(−x) = (−x)³ = −x³ = −f(x). La courbe est symétrique par rapport à O.

3

Équation x³ = c → une seule solution

Toute équation x³ = c admet exactement une solution : x = ∛c (racine cubique de c).

Méthode — Résoudre x³ = c

Exemples de résolution

x³ = 8

x = ∛8 = 2

Car 2³ = 8 ✓

x³ = −27

x = ∛(−27) = −3

Car (−3)³ = −27 ✓

💡 La racine cubique existe toujours (positive ou négative), contrairement à la racine carrée qui n'existe pas pour les négatifs.

II

Fonctions de la forme ax³ + b

Explorez l'effet des paramètres a et b

Définition

Fonctions ax³ + b

Ces fonctions sont de la forme :

f(x) = ax³ + b

où a ≠ 0 est un réel (coefficient directeur) et b est un réel (ordonnée à l'origine).

Labo interactif 🔬

Modifiez a et b — observez la courbe

1 0
f(x) = 1x³ + 0  |  Fonction croissante sur ℝ  |  f(0) = 0
2 propriétés essentielles

Si a > 0

La courbe est en forme de ∫. La fonction est croissante sur ℝ.

f(−∞) = −∞ et f(+∞) = +∞

Si a < 0

La courbe est en forme de ∫ retournée. La fonction est décroissante sur ℝ.

f(−∞) = +∞ et f(+∞) = −∞

⚠️ Le paramètre b translate la courbe vers le haut (b > 0) ou vers le bas (b < 0). Le point (0 ; b) est toujours sur la courbe.

III

Forme a(x−x₁)(x−x₂)(x−x₃)

Racines et allure de la courbe

Définition fondamentale

Polynôme de degré 3 factorisé

Toute fonction de la forme :

f(x) = a(x − x₁)(x − x₂)(x − x₃)

avec a ≠ 0, est un polynôme de degré 3.

Les valeurs x₁, x₂ et x₃ sont les racines du polynôme : ce sont les abscisses où la courbe coupe l'axe des abscisses.

🎯 Si x₁ ≠ x₂ ≠ x₃, la courbe coupe l'axe Ox en 3 points distincts d'abscisses x₁, x₂, x₃.
Labo interactif 🔬

Déplacez les racines et le signe de a

-2
0
2
f(x) = (x+2)(x−0)(x−2)  |  Racines : -2, 0, 2  |  f(0) ≈ 0.0  |  a > 0 ✓
Les 2 allures possibles

a > 0

La courbe monte de gauche à droite en passant par les 3 racines.
Avant x₁ : courbe en bas. Après x₃ : courbe en haut.

a < 0

La courbe descend de gauche à droite en passant par les 3 racines.
Avant x₁ : courbe en haut. Après x₃ : courbe en bas.

Méthode — Lire les racines

Exemple : f(x) = 2(x+1)(x−2)(x−4)

1

Identifier a et les racines

a = 2 > 0. Les racines sont : x₁ = −1, x₂ = 2, x₃ = 4
(on résout x+1=0, x−2=0, x−4=0)

2

Déduire l'allure

a > 0 → courbe qui monte. La courbe coupe l'axe des x en (−1;0), (2;0) et (4;0).

3

Vérifier avec f(0)

f(0) = 2×(0+1)×(0−2)×(0−4) = 2×1×(−2)×(−4) = 16. Le point (0;16) est sur la courbe.
